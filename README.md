## 🏨 PHP Hotel Booking System

<p>🚀 This project is a dynamic and user-friendly Hotel Booking System developed using PHP and MySQL. It enables users to search, book, and manage hotel room reservations efficiently. The system is ideal for learning and real-world implementation in small to medium hotel businesses.</p>

## 🔐 Features

- 🧾 Room Listings – View available rooms with details, pricing, and images
- 📅 Booking System – Book rooms based on availability and dates
- 🧑‍💼 User Registration & Login – Secure authentication system for customers
- 🎨 Clean UI – Simple and responsive user interface using HTML/CSS

## 🛠️ Technologies Used

- PHP – Server-side scripting
- MySQL – Database for storing users, products, and orders
- HTML5 & CSS3 – Frontend layout and design
- JavaScript – Dynamic interactions and cart updates
- XAMPP / WAMP / MAMP – Local development environment
